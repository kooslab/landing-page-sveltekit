# KooStory Repositioning Plan

## The Shift

|                    | Before                                            | After                                                   |
| ------------------ | ------------------------------------------------- | ------------------------------------------------------- |
| **Identity**       | AI workshop provider + custom automation dev shop | AI OS partner for SMEs                                  |
| **Primary offer**  | One-day workshops / custom software               | Build your AI Operating System                          |
| **Delivery label** | Workshop / Development                            | Guided (we build together) / Managed (we build for you) |
| **Relationship**   | Project or event                                  | Ongoing partner                                         |
| **Target**         | Teams wanting to learn AI                         | SME owners who want to scale without hiring             |

---

## Core Positioning

**One-liner:**

> "We help your business run on AI — not just use it."

**Mission:**

> We are the AI operations partner for SMEs who want to do more with the team they already have.

**Vision:**

> Every SME should have access to the same operational leverage that enterprise companies get from large teams. AI is that lever.

**What AI OS means:**
An AI Operating System is not a single tool or automation. It is the intelligence layer built around how your business actually works — your data, your workflows, your expertise — so the business runs on systems, not on individuals.

## The Ladder (internal, not necessarily shown on site)

| Rung | Format            | Description                                          |
| ---- | ----------------- | ---------------------------------------------------- |
| 0    | Hourly consulting | Help owner/team build their AI OS session by session |
| 1    | Audit             | Map workflows, identify AI OS gaps, prioritize       |
| 2    | Project           | Build one workflow end-to-end, prove ROI             |
| 3    | Retainer          | Ongoing AI OS partner — build, maintain, expand      |

Note: "Workshop" is not a separate offering. When hourly consulting involves multiple participants in the room, it looks like a workshop — but the engagement type is the same. Avoid leading with "workshop" as it undersells the relationship.
